- [ ] Mobile navigation and anchor links work

- [ ] Booking/contact links work from navigation, hero, and final CTA

- [ ] Metadata, canonical, Open Graph, sitemap, and robots are complete
- [ ] Restaurant structured data validates using verified values only
- [ ] Analytics events fire for meaningful CTAs
- [ ] Production build is clean
