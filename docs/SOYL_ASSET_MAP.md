# SOYL Asset Map

## Supplied references

- `docs/reference/brand/SOYL Brand Book.pdf` — visual identity reference: logos, colors, typography, patterns, icons, packaging.
- `docs/reference/photography/` — supplied restaurant photography to be reviewed, selected, cropped, optimized, and renamed before integration.

## Brand elements observed

- Wordmark logo with `MIDDLE EASTERN CUISINE` descriptor.
- Olive/tree emblem used as a secondary mark.
- Organic branch/olive line pattern.
- Circular icon language for menu, food, dining, and social actions.
- Core palette around cream, brown, blue, black, white, and a restrained orange accent.
- Editorial serif display typography, with `Tavira` identified as the primary font in the Brand Book.

## Integration rules

- Prefer supplied brand artwork over recreated CSS/SVG approximations.
- Keep original source files in `docs/reference/photography/` untouched until final asset selection is approved.
- Export responsive derivatives to `public/images/` using descriptive names.
- Use modern formats where supported while retaining a safe fallback.
- Optimize the hero separately; do not lazy-load the first meaningful image.
- Do not use stock photography or generated imagery when a relevant supplied asset exists.
